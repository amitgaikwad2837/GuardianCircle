2. Description of the service

GuardianCircle is a free, open-source personal safety application for Android that provides:

  • Manual and automatic SOS alert dispatch to trusted contacts ("guardians")
  • Fall detection and vehicle crash detection using device sensors
  • Journey monitoring with configurable check-in intervals
  • Encrypted peer-to-peer guardian notifications via Firebase Cloud Messaging
  • SMS fallback alerting when internet is unavailable
  • An optional AI safety assistant using user-provided API keys
  • Security features including duress PIN and decoy mode

The app operates entirely on your device. GuardianCircle does not operate any servers, user accounts, or data infrastructure.

3. Safety disclaimer — important

GuardianCircle is a supplementary safety tool. It does not replace professional emergency services. Never delay calling emergency services because you are using this app.

Detection limitations

Fall detection and vehicle crash detection are best-effort features based on accelerometer analysis. They:

  • May not detect all falls or crashes
  • May produce false positives (alerting guardians when no emergency exists)
  • Are affected by device placement, device model, and battery optimisation settings
  • Are not certified medical or automotive safety devices

Delivery limitations

SOS alerts depend on network availability and third-party delivery infrastructure (FCM, SMS carriers). GuardianCircle cannot guarantee:

  • That alerts will be delivered within any specific timeframe
  • That alerts will be delivered at all in areas without network coverage
